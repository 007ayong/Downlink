实用工具提示
下载后遇到音画分离、格式不兼容时，可以用这些 FFmpeg 命令处理。
合并音频和视频
ffmpeg -i video.mp4 -i audio.m4a -c copy output.mp4
转为通用 MP4
ffmpeg -i input.mkv -c:v copy -c:a aac output.mp4
提取音频
ffmpeg -i input.mp4 -vn -c:a copy audio.m4a
